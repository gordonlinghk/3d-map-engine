# @map-engine/ui

React UI for map-engine demos: search bar (Fuse.js), atlas list with category chips, info panel, toolbar, canvas minimap, HUD.

```tsx
import { AtlasUI } from '@map-engine/ui';
import '@map-engine/ui/index.css';

<AtlasUI renderer={renderer} world={world} />
```

Peer dependencies: `react >= 18`, `react-dom >= 18`. Live demo & docs: https://github.com/gordonlinghk/3d-map-engine
